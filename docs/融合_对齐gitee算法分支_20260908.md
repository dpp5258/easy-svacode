## 二、保留边界（以 gitee 覆盖时**有意保留**的 github 侧内容）

| 保留项 | 原因 |
|---|---|
| `SVA-web/vue.config.js` | **github 独有的 `@opentiny` babel 转译修复**（quill2/webpack4）；gitee 版无此规则，但 gitee 自身 web 也用了 6 处 opentiny——若直接用 gitee 版会破坏本仓库 web 构建 |
| 统一仓库骨架 | `easySVA/`、`SVA-mediaServer/`、`scripts/`、`setup.sh`、`AGENTS.md`（gitee 无，属 github 5 仓库合并版专有） |
| 根 `README.md`、`.gitignore` | 两仓库定位不同，根文件描述各自仓库 |
| `docs/修复记录汇总.md`、`docs/启动步骤.md`、`docs/Vstream.txt` | github 侧本有记录（copy 不删除） |
| 顶层目录 | gitee 独有 `changes/ models/ db-backup/ records/` 未收录进分支（权威源在 `/opt/SVA` 与本地镜像 `easy-svacode-gitee/`） |
